# Implementação de devices

Este documento descreve o processo de integração de dispositivos dispositivos em aplicações Android/Flutter, incluindo configuração de impressão, permissões, dependências e observações específicas de fabricantes.

---

# Visão Geral

A integração de dispositivos normalmente envolve:

- Instalação de drivers específicos
- Inclusão de bibliotecas proprietárias
- Configuração de permissões Android
- Integração com APIs de impressão
- Configuração de comunicação AIDL/SDK
- Ajustes específicos por fabricante

Cada fabricante possui sua própria SDK, documentação e requisitos.

---

# Estrutura Recomendada

Arquivos geralmente utilizados durante a integração:

```text
android/app/libs/
android/app/build.gradle
android/app/src/main/AndroidManifest.xml
```

## Instalação de Driver

Em alguns dispositivos é necessário instalar drivers específicos para comunicação com o computador.

```text
Landi Win Driver
```

---

## Biblioteca de Impressão

Adicione o arquivo `.jar` fornecido pelo fabricante dentro da pasta:

```text
android/app/libs/
```

Exemplo:

```text
usdk_api_aidl.jar
```

---

## Dependências Gradle

Adicione as dependências necessárias no arquivo:

```text
android/app/build.gradle
```

Exemplo:

```gradle
implementation files('libs/usdk_api_aidl.jar')

implementation 'com.google.zxing:core:3.4.1'
implementation 'com.google.zxing:javase:3.4.1'
```

---

## Permissões Android

Adicione as permissões necessárias no:

```text
AndroidManifest.xml
```

Exemplo:

```xml
<uses-permission android:name="android.permission.BIND_PRINT_SERVICE"/>
<uses-permission android:name="android.permission.WRITE_EXTERNAL_STORAGE"/>
<uses-permission android:name="android.permission.SYSTEM_ALERT_WINDOW"/>
<uses-permission android:name="android.permission.FOREGROUND_SERVICE"/>
```

Dependendo do SDK utilizado, permissões adicionais podem ser necessárias.

---

```text

Adicione:

```

---

## Compatibilidade Android 11+

Para dispositivos Android 11 ou superior pode ser necessário adicionar:

```xml
<queries>
    <package android:name="woyou.aidlservice.jiuiv5"/>
</queries>
```

Essa configuração permite localizar serviços internos utilizados pela impressora.

## Configuração de Debug

Em alguns modelos, para permitir comunicação em modo debug:

1. Ligue o dispositivo sem cabos conectados
2. Após inicializar:
   - conecte primeiro no dispositivo
   - depois conecte ao computador

Esse processo pode evitar falhas de reconhecimento USB.

# Observações Importantes

- Cada fabricante possui APIs diferentes
- Algumas SDKs dependem de AIDL
- Nem todos os dispositivos possuem as mesmas permissões
- Android 11+ pode exigir configurações extras
- Sempre valide em hardware físico
- Prefira manter documentação local disponível
