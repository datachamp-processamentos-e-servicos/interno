# O que é o dt.Mobile

O **dt.mobile** é um sistema para potencializar o desempenho da equipe comercial, ampliando os resultados de representantes, vendedores e administradores por meio de recursos práticos e eficientes.

Com o aplicativo é possível realizar vendas, cadastrar clientes e produtos e registrar visitas comerciais — tudo **sem necessidade de conexão com a internet**. As operações realizadas offline podem ser sincronizadas posteriormente assim que a conexão for restabelecida.

:::tip[Integração com o Sentus]
O dt.Mobile é ainda mais completo para clientes Datachamp que utilizam o **Sentus Web**, permitindo sincronização automática de clientes, itens, formas de pagamento e muito mais.
:::

## 8. Venda Fora do Estabelecimento

Disponível apenas na integração com o Sentus.

### 8.1 Carga

Antes de iniciar vendas fora do estabelecimento, é necessário registrar uma carga:

1. Acesse **Menu Lateral → Venda Fora do Estab. → Carga**
2. Escaneie o código de barras ou digite a chave da **NF-e**
3. A NF-e aparece como cartão com: número, data de emissão, valor total e quantidade de itens
4. Clique em **Encerrar Carga** para remover a NF-e ativa

A tela **Itens da Carga** exibe os itens da NF-e registrada com código, nome, NFe de origem, quantidade disponível e cálculo de valor.

### 8.2 Nova Venda

| Campo | Descrição |
|-------|-----------|
| Emissão | Editável via calendário |
| Tipo | NF-e ou NFC-e |
| Operação | Operação da venda |
| Matriz Comercial | Define preços conforme matriz selecionada |
| Cliente | Redireciona para listagem de clientes |
| Itens | Itens, Quantidade, Mercadoria, Total + menu de Desconto e Impostos |
| Pagamento | Redireciona para formas de pagamento |
| Observações | Campo livre |

### 8.3 Vendas

A listagem exibe as vendas com: código e nome do cliente, tipo de nota, valor, emissão e status.

**Status possíveis:** Novo, Em processamento, Rejeitada, Autorizado, Denegada, Cancelado, Encerrado.

**Ações por venda (menu ⋮):** Editar, Remover, Ligar, Enviar.

### 8.4 Repasse

Permite registrar repasses ao ERP. Campos da criação: data de emissão (não editável), valor, cliente (obrigatório) e observação. Ações por repasse: Remover, Sincronizar, Recibo.

## 15. Sincronização

Disponível apenas na integração com o **Sentus**.

### 15.1 Receber Dados

Importa dados do Sentus Web para o app: clientes, itens, formas de pagamento, matrizes comerciais e compras.

| Tipo de Sincronização | Descrição |
|-----------------------|-----------|
| **Total** | Recria inteiramente a base de dados (obrigatória no primeiro acesso) |
| **Incremental** | Apenas dados modificados após a última sincronização |
| **Últimas 24h / 48h** | Apenas dados modificados no período |
| **Apenas últimas compras** | Somente histórico de compras |

:::tip[Cuidado]
Quanto maior o período selecionado na sincronização Total, mais tempo ela levará.
:::

Marcadores disponíveis: **Dados Cadastrais** (obrigatório), **Dados Comerciais** (obrigatório), **Últimas Compras** (opcional).

### 15.2 Enviar Dados

Envia para o Sentus Web os dados gerados no app: atendimentos, clientes, pedidos, vendas, orçamentos e repasses. É possível selecionar quais tipos de dados serão enviados.

### 15.3 Exportar

Gera um arquivo **.CSV** dos pedidos realizados no app. Permite filtrar por período (Data Inicial e Data Final).

## 16. Configurações E-mail

Disponível apenas na integração por **E-mail** (Menu Lateral → Configurações).

### 16.1 Empresa

Tela de cadastro e edição dos dados da empresa representada. Para Pessoa Jurídica, o campo CPF é substituído por CNPJ e o campo Nome Fantasia é exibido.

Campos: Código, CPF/CNPJ, Nome, Nome Fantasia (PJ), Ind IE, I.E., CEP, Município, UF, Logradouro, Número, Bairro, Complemento, E-mail, Telefone, Tags, Situação, Observações.

### 16.2 Importar (Clientes/Produtos)

Permite importar clientes ou itens a partir de arquivos **.CSV** ou **.TXT**. Após o upload, os dados extraídos são exibidos em uma listagem de pré-visualização antes de serem salvos.

### 16.3 Exportar (Clientes, Itens e Pedidos)

Gera arquivos **.CSV** dos dados cadastrados. Tipos disponíveis: Clientes, Itens e Pedidos.

Para Pedidos, é possível escolher entre exportar **Todos** ou apenas pedidos de um **período específico** (Data Inicial e Data Final).
