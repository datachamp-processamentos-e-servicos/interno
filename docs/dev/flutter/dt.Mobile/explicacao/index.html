O que é o dt.Mobile

O dt.mobile é um sistema para potencializar o desempenho da equipe comercial, ampliando os resultados de representantes, vendedores e administradores por meio de recursos práticos e eficientes.

Com o aplicativo é possível realizar vendas, cadastrar clientes e produtos e registrar visitas comerciais — tudo sem necessidade de conexão com a internet. As operações realizadas offline podem ser sincronizadas posteriormente assim que a conexão for restabelecida.

Integração com o Sentus

O dt.Mobile é ainda mais completo para clientes Datachamp que utilizam o Sentus Web, permitindo sincronização automática de clientes, itens, formas de pagamento e muito mais.

1. Configuração​

1.1 Primeira Tela​

Ao abrir o aplicativo pela primeira vez, é exibida a tela de boas-vindas informando que o sistema foi desenvolvido exclusivamente para representantes comerciais. Clique em Avançar para prosseguir.

1.2 Tipo de Integração​

Na tela seguinte, o usuário escolhe como irá utilizar o aplicativo:

  • 🔗 Sentus
  • 📧 E-mail

Para usuários com cadastro no Sentus Web. Ao avançar, o usuário é encaminhado para o login via Sentus e obtém acesso automático a todos os cadastros do ERP.

Para usuários sem acesso ao Sentus. O cadastro é feito por e-mail ou conta Google. Neste modo, os cadastros de clientes e produtos são gerenciados manualmente pelo próprio usuário.

1.3 Login​

  • 🔗 Sentus
  • 📧 E-mail
  • Usuário — nome de login com domínio (ex: usuario@empresa, não apenas usuario)
  • Senha — mesma senha utilizada no Sentus Web

Um botão no canto superior esquerdo lista os usuários que já realizaram login anteriormente. Caso o login selecionado não tenha sido acessado há mais de 10 dias, a senha será solicitada novamente.

  • Usuário — e-mail cadastrado na criação da conta
  • Senha — senha definida no cadastro

Opções adicionais disponíveis nesta tela:

  • Esqueci minha senha — envia e-mail de recuperação
  • Acessar com o Google — autenticação via conta Google
  • Cadastre-se — redireciona para a criação de conta

1.4 Cadastro por E-mail​

Disponível apenas na integração por e-mail. Campos obrigatórios:

  • E-mail — será usado para autenticação
  • Senha — mínimo de seis caracteres
  • Repita a senha — confirmação da senha

Após preencher todos os campos e clicar em Criar Conta, um e-mail de confirmação será enviado. O cadastro só é liberado após a confirmação do link recebido.

2. Primeiro Acesso​

  • 🔗 Sentus
  • 📧 E-mail

Ao realizar o primeiro acesso via Sentus, um diálogo solicita a sincronização inicial com o ERP.

:::warning Sincronização obrigatória

Cancelar a sincronização inicial restringe severamente o uso do aplicativo, pois a maior parte dos dados essenciais ainda não estará disponível.

:::

Uma notificação no topo da tela solicita a conclusão do cadastro. Ao clicar em Configurar, campos adicionais são solicitados:

  • CPF*, Nome*, UF*, Município* — obrigatórios
  • Telefone, CEP, Número, Complemento, Bairro — opcionais

Em seguida, o usuário define seu perfil de atuação: representante autônomo (pode representar várias empresas) ou vinculado a uma única empresa (necessário cadastrar a empresa na próxima etapa).

3. Tela Principal​

  • 🔗 Sentus
  • 📧 E-mail

Após a sincronização inicial, a tela principal exibe:

  • Menu Lateral — botão no canto superior esquerdo com acesso a todas as funcionalidades
  • Nome e Logo da Empresa — empresa vinculada ao representante autenticado
  • Notificação — avisos e comunicados configurados pela empresa (opcional)
  • Botão flutuante (+) — criação rápida de pedido ou venda (venda disponível após iniciar uma carga)
  • Menu inferior — acesso rápido a Clientes, Itens, Pedidos e Atendimentos

A tela principal exibe:

  • Menu Lateral — botão no canto superior esquerdo com acesso às funcionalidades disponíveis
  • Logo da Empresa — logotipo cadastrado pelo usuário
  • Botão flutuante (+) — criação rápida de pedido
  • Menu inferior — acesso rápido a Clientes, Itens, Pedidos e Atendimentos

O canto superior direito possui um menu com Política de Privacidade, Ajuda e Compartilhar Logs (uso do suporte Datachamp).

5. Configurações do Usuário​

5.1 Perfil​

Exibe as informações do representante autenticado. Os campos variam conforme o tipo de pessoa:

  • 🏢 Pessoa Jurídica
  • 👤 Pessoa Física

Código, CNPJ, Nome, Nome Fantasia, Ind IE, Inscrição Estadual, Regime Tributário, CEP, Município, UF, Logradouro, Número, Bairro, Complemento, E-mail, Telefone, Tags, Situação, Informações, Observações.

Código, CPF, Nome, Ind IE, Inscrição Estadual, CEP, Município, UF, Logradouro, Número, Bairro, Complemento, E-mail, Telefone, Tags, Situação, Observações.

5.2 Backup​

Selecione a Base Principal e/ou a Base Usuário e clique em Exportar para salvar os arquivos de backup no dispositivo.

5.3 Restaurar​

Selecione a base desejada e clique em Restaurar. Todos os dados existentes serão apagados e substituídos pelo backup selecionado.

Cuidado

A operação de restauração é irreversível.

5.4 Usuários​

Lista os usuários autenticados no aplicativo. É possível remover um usuário ou adicionar um novo clicando no botão + (redireciona para a tela de login).

5.5 Sair da Conta​

Encerra a sessão do usuário atual e redireciona para a tela de login.

6. Pedidos​

  • 🔗 Sentus
  • 📧 E-mail

Exibe os pedidos em cartões com: código e nome do cliente, número, valor, data de emissão, data de embarque e status.

Status possíveis: Sincronizado, Não sincronizado, Pendências, Não aprovado, Não sincronizado por pendências, Excluído.

Ações por pedido (menu ⋮): PDF, Editar, Visualizar, Acompanhamento, Duplicar, Remover, Ligar.

Exibe os pedidos em cartões com: código e nome do cliente, número, valor, data de emissão, data de embarque e situação.

Situações possíveis: Novo, Faturado, Encerrado, Cancelado.

Ações por pedido (menu ⋮): PDF, Editar, Duplicar, Remover, Ligar.

A busca avançada (botão ⋮ ao lado da pesquisa) permite filtrar por data, cliente, operação e status/situação.

7. Orçamentos​

Disponível apenas na integração com o Sentus.

A tela de listagem exibe orçamentos em cartões com: código e nome do cliente, número, valor, datas e status (Novo / Finalizado). Ações disponíveis: PDF, Visualizar, Duplicar, Remover.

A tela de criação é idêntica à de pedidos, com um cartão informativo destacando que se trata de um orçamento. Campos: Estabelecimento, Emissão, Operação, Frete, Cliente, Transportadora, Itens, Pagamento, Observações.

8. Venda Fora do Estabelecimento​

Disponível apenas na integração com o Sentus.

8.1 Carga​

Antes de iniciar vendas fora do estabelecimento, é necessário registrar uma carga:

  1. Acesse Menu Lateral → Venda Fora do Estab. → Carga
  2. Escaneie o código de barras ou digite a chave da NF-e
  3. A NF-e aparece como cartão com: número, data de emissão, valor total e quantidade de itens
  4. Clique em Encerrar Carga para remover a NF-e ativa

A tela Itens da Carga exibe os itens da NF-e registrada com código, nome, NFe de origem, quantidade disponível e cálculo de valor.

8.2 Nova Venda​

CampoDescrição
EmissãoEditável via calendário
TipoNF-e ou NFC-e
OperaçãoOperação da venda
Matriz ComercialDefine preços conforme matriz selecionada
ClienteRedireciona para listagem de clientes
ItensItens, Quantidade, Mercadoria, Total + menu de Desconto e Impostos
PagamentoRedireciona para formas de pagamento
ObservaçõesCampo livre

8.3 Vendas​

A listagem exibe as vendas com: código e nome do cliente, tipo de nota, valor, emissão e status.

Status possíveis: Novo, Em processamento, Rejeitada, Autorizado, Denegada, Cancelado, Encerrado.

Ações por venda (menu ⋮): Editar, Remover, Ligar, Enviar.

8.4 Repasse​

Permite registrar repasses ao ERP. Campos da criação: data de emissão (não editável), valor, cliente (obrigatório) e observação. Ações por repasse: Remover, Sincronizar, Recibo.

9. Atendimentos​

Atenção

Disponível apenas na integração com o Sentus.

A listagem exibe os atendimentos com: nome do cliente, data, número e status (Aguardando envio ou Sincronizado). Ações variam conforme o status: sincronizar ou remover.

Criação de Atendimento​

Campos obrigatórios: Emissão, Modalidade (Presencial ou Remoto) e Cliente. Campo opcional: Observações.

O botão Sincronizar Atendimento define se o atendimento será enviado ao ERP após salvar. É possível anexar fotos via câmera ou galeria.

Todos os relatórios possuem uma tela de filtro antes do resultado. Os filtros comuns são Data Inicial e Data Final. Após clicar em Pesquisar, o usuário é encaminhado para a tela do relatório.

11. Clientes​

11.1 Listagem de Clientes​

  • 🔗 Sentus
  • 📧 E-mail

Cartões exibem nome, código e endereço. Botões rápidos no cartão: Telefone, WhatsApp, Cédula (posição financeira), Envelope (e-mail), Relógio (últimas compras), Localização.

Indicadores de situação por cor do cartão:

  • Branco — ativo
  • Amarelo — restrição
  • Azul — orçamento ou pedido em aberto
  • Vermelho escuro — bloqueado
  • Vermelho claro — inativo

Cartões exibem nome, código e endereço. Botões rápidos: Telefone, WhatsApp, Envelope, Relógio, Localização.

Indicadores de situação por cor do cartão:

  • Branco — ativo
  • Amarelo — restrição
  • Vermelho escuro — bloqueado
  • Vermelho claro — inativo

A busca avançada permite filtrar por UF, Município, Situação e Tags.

11.2 Cadastro de Cliente​

  • 👤 Pessoa Física
  • 🏢 Pessoa Jurídica

Campos: Código, CPF, Nome, Ind IE, I.E., CEP, Município, UF, Logradouro, Número, Bairro, Complemento, E-mail, Telefone, Tags, Situação, Observações, Horário de Entrega, Tipo de Cliente.

Campos adicionais em relação à Pessoa Física: CNPJ (com botão de consulta), Nome Fantasia, Regime Tributário.

12. Itens​

12.1 Listagem de Itens​

  • 🔗 Sentus
  • 📧 E-mail

Cartões exibem código, nome, unidade comercial, grupo, preço e imagem. Ações no menu ⋮: Imagens, Última Atualização, Últimas Vendas.

Mesmas informações que o Sentus. Ações adicionais no menu ⋮: Remover.

Botão + na parte inferior direciona para o cadastro de item.

Cores dos cartões: Branco (ativo), Amarelo (bloqueado ou restrito), Vermelho (inativo).

A busca avançada permite filtrar por Nome, Referência, Grupo de Produtos e Ordenação (Nome, Referência, Grupo+Nome, Grupo+Referência, Data de Alteração).

13. Grupo de Itens​

  • 🔗 Sentus
  • 📧 E-mail

Exibe grupos sincronizados do Sentus Web. A edição não é permitida pelo app — deve ser feita no Sentus Web. Ao clicar em um grupo, são exibidos campos de visualização: Descrição, Situação, Observações e ID de Origem.

Um grupo "Diversos" é criado automaticamente no primeiro acesso. Grupos podem ser criados, editados e removidos pelo usuário.

Campos do cadastro: Descrição (obrigatório), Situação (opcional), Observação (opcional).

:::warning Exclusão permanente: uma vez removido, o grupo não pode ser recuperado. :::

14. Formas de Pagamento​

  • 🔗 Sentus
  • 📧 E-mail

Exibe formas de pagamento sincronizadas do Sentus Web. A edição não é permitida pelo app. Ao clicar, são exibidos: Código, Nome, Cobrança, Modalidade e ID de Origem.

Uma forma "À VISTA" é criada automaticamente. O usuário pode criar, editar e remover formas.

Campos do cadastro:

  • Nome (obrigatório)
  • Cobrança (opcional)
  • Modalidade (opcional) — Dinheiro, Cheque, Cartão de Crédito, Cartão de Débito, PIX, Boleto Bancário, entre outros
  • Situação (padrão: Ativo)

15. Sincronização​

Disponível apenas na integração com o Sentus.

15.1 Receber Dados​

Importa dados do Sentus Web para o app: clientes, itens, formas de pagamento, matrizes comerciais e compras.

Tipo de SincronizaçãoDescrição
TotalRecria inteiramente a base de dados (obrigatória no primeiro acesso)
IncrementalApenas dados modificados após a última sincronização
Últimas 24h / 48hApenas dados modificados no período
Apenas últimas comprasSomente histórico de compras
Cuidado

Quanto maior o período selecionado na sincronização Total, mais tempo ela levará.

Marcadores disponíveis: Dados Cadastrais (obrigatório), Dados Comerciais (obrigatório), Últimas Compras (opcional).

15.2 Enviar Dados​

Envia para o Sentus Web os dados gerados no app: atendimentos, clientes, pedidos, vendas, orçamentos e repasses. É possível selecionar quais tipos de dados serão enviados.

15.3 Exportar​

Gera um arquivo .CSV dos pedidos realizados no app. Permite filtrar por período (Data Inicial e Data Final).

16. Configurações E-mail​

Disponível apenas na integração por E-mail (Menu Lateral → Configurações).

16.1 Empresa​

Tela de cadastro e edição dos dados da empresa representada. Para Pessoa Jurídica, o campo CPF é substituído por CNPJ e o campo Nome Fantasia é exibido.

Campos: Código, CPF/CNPJ, Nome, Nome Fantasia (PJ), Ind IE, I.E., CEP, Município, UF, Logradouro, Número, Bairro, Complemento, E-mail, Telefone, Tags, Situação, Observações.

16.2 Importar (Clientes/Produtos)​

Permite importar clientes ou itens a partir de arquivos .CSV ou .TXT. Após o upload, os dados extraídos são exibidos em uma listagem de pré-visualização antes de serem salvos.

16.3 Exportar (Clientes, Itens e Pedidos)​

Gera arquivos .CSV dos dados cadastrados. Tipos disponíveis: Clientes, Itens e Pedidos.

Para Pedidos, é possível escolher entre exportar Todos ou apenas pedidos de um período específico (Data Inicial e Data Final).
