## Como contribuir com a documentação

Esta documentação é **viva** — qualquer pessoa da equipe pode e deve contribuir.

1. Acesse o repositório no GitHub da organização `datachamp-processamentos-e-servicos`
2. Edite ou crie arquivos `.md` / `.mdx` na pasta `docs/`
3. Abra um Pull Request com suas alterações
4. Após aprovação, o deploy é automático via GitHub Actions

:::info Formato dos arquivos
Os arquivos de documentação usam **Markdown** (`.md`) ou **MDX** (`.mdx`).  
MDX permite usar componentes React diretamente no texto — como as abas acima.
:::
