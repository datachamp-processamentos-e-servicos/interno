:::tip[Dica rápida]
Use a **barra de busca** (atalho `Ctrl+K` / `Cmd+K`) para encontrar qualquer conteúdo rapidamente.

Os principais produtos documentados nesta base:

| Produto | Descrição | Stack |
|---------|-----------|-------|
| **SENTUS / PDV** | Sistema de ponto de venda para o varejo | Flutter, Dart |
| **Portal Web** | Interface de gestão e relatórios | Web |
| **Integrações** | Banco do Brasil, Goomer, gateways de pagamento | Java, Quarkus |
