# Editar uma página

## Introdução

Para editar uma página já existente no Docusaurus, basta alterar o arquivo `.mdx` correspondente dentro do repositório no GitHub.

---

## Como encontrar a página

### 1. Acesse o repositório

Abra o repositório da documentação no GitHub.

Exemplo:

```txt
https://github.com/datachamp-processamentos-e-servicos/docusaurus/tree/main/docs
```


### 2. Vá até a pasta `docs`

Os arquivos da documentação ficam dentro da pasta:

```bash
/docs
```


### 3. Entre na pasta da documentação

Exemplo:

```bash
/docs/sentus/
```


### 4. Localize o arquivo `.mdx`

Exemplo:

```bash
tutorial-login.mdx
```

---

## Como editar

### 1. Abra o arquivo

Clique no arquivo desejado.


### 2. Clique no ícone de edição

No canto superior direito do arquivo, clique no ícone de lápis.


### 3. Faça as alterações

Você pode editar:

- títulos
- textos
- listas
- imagens
- links
- vídeos
- códigos

---


## Salvando a alteração

Para salvar as alterações, deve-se utilizar o mesmo 
padrão de postagem do [Criar uma Página](./create-a-page.mdx#postando-o-artigo).


---

## Publicação automática

Após o commit:

- o GitHub Actions iniciará automaticamente
- o site será atualizado
- a alteração ficará disponível após o deploy finalizar


---

## Como verificar se atualizou

Para validar se o site foi atualizado, siga o passo a passo do [Validar Postagem](./autopost-tutorial.mdx).


---

## Resumo

Para editar uma página:

1. Abra o arquivo `.mdx`
2. Clique em editar
3. Faça as alterações
4. Realize o commit
5. Aguarde o deploy automático
