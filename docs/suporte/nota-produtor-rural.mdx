# Entrada de produtos por Nota Fria

Para realizar a entrada de produtos utilizando uma **Nota Fria**, acesse:

```text
Suprimentos → Notas de Entrada → Novo
```

Na criação da nota:

- Selecione a opção **Não é uma NFe**.

:::info

Para facilitar a identificação, utilize alguma característica que indique que se trata de uma **Nota Fria**, como por exemplo a **Série A**.

:::
