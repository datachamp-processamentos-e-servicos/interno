# Criar usuário no Sentus Master

No **Sentus Master**, acesse:

```text
Administrativo → Master User → Novo
```

## Usuários

Devem ser criados os seguintes usuários:

| Tipo | Login | Senha |
|------|-------|-------|
| Cliente | `admin@cliente` | `123465` |
| Suporte | `root@cliente` | `@tu4l1t4` |

## Nome

No campo **Nome**, informe o tipo de usuário seguido do nome da empresa.

Exemplos:

- Admin Datachamp
- Root Datachamp

### Tenant Parceria

Quando a empresa for **Santiago**, criar também o usuário:

- **Parceria** (papel **root**)
- Senha: `@tu4l1t4`

## Configurações

- Selecionar a **tenant** correspondente ao cliente.
- Definir **Tempo da Sessão** como **0**.
