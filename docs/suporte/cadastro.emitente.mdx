# Cadastro de Emitente

## Passo a Passso

1. Acesse:

```
Cadastro → Emitentes
```

2. Clique em **Novo**.

3. Informe o CNPJ.

4. Consultar os dados:

  - SEFAZ;
  - SINTREGA (para empresas de outros estados).

5. Salve o cadastro.

---

## Importante

Após salvar e sair do emitente:

> Alguns campos serão preenchidos automaticamente.

retorne ao cadastro e informe:

- Regime Tributário;
- Perfil Tributário;
- Tipo de Atividade;
- Tipo Emitente MDF-e (quando aplicável);
- Certificado Digital;
- Ambiente NF-e.
