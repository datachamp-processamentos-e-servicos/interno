# Atualizar Arquivo PDF do DT.Shop

## Passo a Passo

1. Localize o arquivo PDF em:
```
G:/_Sentus/E-mails de atualização do sistema - Dt.Shop
```

2. No computador do Gui:
- Abrir o software **WinPro**;
- selecionar **Nova Sessão**.

3. Copiar o arquivo PDF.

4. Inserir o arquivo no seguinte diretório:

```
/dev/var/wwww/datachamp.com.br/html/downloads/dt.shop
```
