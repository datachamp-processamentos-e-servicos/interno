# Certificado Digital - NFSe Carlos Barbosa

Acesse a aba:

```text
Integração → Download do Certificado
```

Em seguida:

1. Clique em **Download do Certificado**.
2. Informe uma senha para o certificado.
3. Clique em **Gerar**.
4. Após a geração, clique em **Download** para baixar o certificado.

:::info

A senha informada será utilizada para proteger o certificado. Guarde-a, pois ela será necessária para futuras importações ou instalações.

:::
