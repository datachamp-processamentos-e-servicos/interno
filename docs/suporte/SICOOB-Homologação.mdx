# Homologação Bancária - Sicoob

## Como realizar a homologação

O processo de homologação do Sicoob é realizado por meio do Portal de Homologação disponibilizado pelo banco.

Normalmente, o Sicoob encaminha um e-mail contendo todas as informações necessárias para o processo, incluindo:

- Dados para configuração do portador no Sentus;
- Login de acesso ao portal;
- Número de protocolo da homologação.

:::tip[Dica]

Guarde o e-mail recebido do Sicoob, pois ele contém todas as informações necessárias para acessar o portal e concluir o processo de homologação.

:::

## Acesso ao Portal

Para acessar o Portal de Homologação:

1. Utilize o **CNPJ do cliente** como usuário;
2. Utilize o **Número do Protocolo** informado no e-mail como senha ou credencial de acesso;
3. Na tela de login, informe que você é um **Desenvolvedor**.

Todas essas informações são fornecidas pelo próprio Sicoob no e-mail enviado durante a abertura do processo.

## Configuração do Portador

Antes de iniciar os testes, realize o cadastro do portador no Sentus utilizando os dados informados pelo banco.

Verifique atentamente as seguintes informações:

- Agência;
- Conta Corrente;
- Convênio;
- Carteira;
- Demais dados informados pelo Sicoob.

## Processo de Homologação

Após acessar o portal:

1. Siga as orientações apresentadas em cada etapa;
2. Gere os arquivos necessários através do Sentus;
3. Realize os envios solicitados pelo portal;
4. Aguarde as validações realizadas pelo Sicoob.

Na maioria dos casos, toda a execução técnica é realizada pela equipe de sistemas, enquanto a validação dos dados é feita por um analista do banco.

## Conclusão da Homologação

:::warning[Importante]

Durante o processo, acompanhe as mensagens e orientações disponibilizadas pelo analista responsável pela homologação.

Basta seguir as instruções fornecidas dentro do próprio processo para realizar os ajustes necessários e concluir a homologação com sucesso.

:::
