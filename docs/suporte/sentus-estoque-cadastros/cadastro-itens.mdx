# Atualizar Cadastros de Itens - SENTUS

:::info[Observação]

A partir da coluna **16**, os campos são opcionais.

:::

## Campos do arquivo

```text
00-ID (Pode ser em branco)
01-Referência
02-Nome
03-Unidade [ID ou Descrição]
04-Preço
05-Preço de Custo
06-NCM
07-CEST
08-CST ICMS
09-EAN (Código de Barras)
10-Marca
11-Peso Bruto
12-Peso Líquido
13-Cubagem
14-Grupo do Item [ID]
15-Grupo Tributário [ID]
```

## Campos opcionais

```text
16-Observação
17-Especificação
18-Informação Adicional
19-Tags
20-Depósito [ID]
21-Depósito - Quantidade
22-Depósito - Valor
```
