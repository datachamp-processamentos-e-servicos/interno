# Manual de Ajuda – Passo a Passo

## Localizar os manuais de ajuda

Os manuais de ajuda estão disponíveis no seguinte caminho:

```text
G:\_Cris\Menus Cris
```

Os documentos estão organizados por módulos.

> **Importante:** Caso seja necessário editar um manual, salve-o novamente no formato **PDF**.

## Configurar o link de ajuda no Sentus

1. Acesse o **tenant `@master`**.
2. Vá em **Opções**.
3. Selecione o módulo desejado.
4. Clique na **seta** para editar.
5. Abra o documento PDF correspondente e copie o seu link.
6. Cole o link no campo **Link Ajuda**.
7. Salve as alterações.

## Publicar um PDF no Sentus

1. Acesse o seguinte caminho:

```text
G:\_Dev\Programs\WinSCP5177
```

2. Execute o **WinSCP**.

3. Na janela que será aberta, clique em **Nova sessão**.

4. O usuário já estará configurado. Basta clicar em **Login**.

5. Acesse a pasta **ajuda**.

6. Nessa pasta estarão todos os arquivos PDF disponíveis no Sentus. Adicione ou substitua o documento conforme necessário.
