# Como instalar o PAYER

:::note Antes de começar
Ao posicionar o cursor sobre os campos do sistema, poderão ser exibidas orientações adicionais para auxiliar no preenchimento.
:::

**Como realizar**

Acesse o endereço:

[Downloads DataChamp](https://www.datachamp.com.br/downloads/)

Em seguida:

1. Abra a pasta **DTshop/**.
2. Acesse a pasta **TEF/**.
3. Localize e abra o passo a passo referente ao **PAYER**.
4. Na página exibida, copie o endereço de instalação iniciado por **https://**.
5. Abra uma nova aba no navegador e cole o endereço copiado.
6. Pressione **Enter** para iniciar o download ou a instalação do PAYER.

**Informações**

Normalmente, após acessar o endereço do PAYER em uma nova aba, a instalação será iniciada automaticamente.

Caso o processo não seja iniciado, verifique se o navegador bloqueou o download ou a abertura da página.

## Dados para contratação do TEF PAYER

Solicite as seguintes informações do responsável:

- Nome do responsável
- CPF
- E-mail
- Celular
- Data de nascimento
- Nome da mãe
- Endereço

## Como contratar

### Pelo aplicativo

Realize a contratação pelo aplicativo.

### Pelo portal

Abra um ticket no portal:

https://payer.tomticket.com/helpdesk

Credenciais:

- **Usuário:** guilherme@datachamp.com.br
- **Senha:** Acesso@123

No atendimento, informe:

- Números lógicos
- Roteamento
- Se o PIX será **PAYER** ou **Multibanco**
- Chaves PIX necessárias

## Contratar e ativar na Smart POS Multiadquirente

1. No aplicativo, adicione o módulo **Smart POS**.
2. No atendimento aberto no portal, informe o **modelo da Smart POS**.
3. Aguarde o envio do **QR Code de configuração**.
4. Conecte a Smart POS à internet.
5. Acesse o **GertecBox**.
6. Leia o QR Code recebido.
7. Aguarde a instalação automática dos aplicativos:
   - PAYER
   - DT.Shop
8. Realize a configuração dos aplicativos.

:::tip[Importante]

Verifique se a Smart POS possui acesso à internet antes de iniciar a configuração.

:::
