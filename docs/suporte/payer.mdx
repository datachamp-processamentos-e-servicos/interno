# PAYER

## Passo a passo para instalação e configuração do TEF PAYER

### 1. Preparar o computador

1. Desinstale ou desative o antivírus, caso ele esteja bloqueando a instalação.
2. Verifique se existe uma nova atualização disponível para o **DT.Shop**.
3. Caso exista uma versão mais recente, atualize o DT.Shop antes de continuar.

### 2. Localizar os dados do cliente

1. Acesse o cadastro de **Participantes**.
2. Localize o participante referente ao cliente.
3. Utilize os dados disponíveis no cadastro para facilitar o preenchimento das configurações.
4. Copie o **CNPJ** do participante.
5. Acesse a aba **Observação**.
6. Localize o **token do PAYER** disponível nas observações.

:::tip[Dica]

Sempre que possível, copie os dados diretamente do cadastro de **Participantes**, principalmente o CNPJ, para evitar erros de digitação.

:::

### 3. Instalar o PAYER

Também é possível baixar o instalador diretamente pelo link abaixo:

[Baixar o instalador do PAYER — versão 1.29.10](https://checkout-apps2.s3.amazonaws.com/setup_payer_checkout_v1.29.10-beta.exe)

Normalmente, ao acessar o endereço, o download será iniciado automaticamente.

Caso o download não seja iniciado, verifique se o navegador bloqueou o download ou a abertura da página.

Caso não funcione:

1. Acesse [Downloads DataChamp](https://www.datachamp.com.br/downloads/).
2. Abra a pasta **DTshop/**.
3. Acesse a pasta **TEF/**.
4. Localize e abra o passo a passo referente ao **PAYER**.
5. Na página exibida, copie o endereço de instalação iniciado por **https://**.
6. Abra uma nova aba no navegador.
7. Cole o endereço copiado.
8. Pressione **Enter** para iniciar o download ou a instalação do PAYER.

## Configuração no DT.Shop

Após instalar o PAYER:

1. Abra as configurações do **DT.Shop**.
2. Informe a senha:

   `@tu4l1t4`

3. Acesse **Configurações TEF**.
4. Preencha os campos de usuário utilizando os dados disponíveis no cadastro de **Participantes**.
5. Confira os dados informados antes de salvar.

---

## Configuração no PAYER

1. Abra o **PAYER**.
2. Informe o **CNPJ** do cliente.
3. Informe o **token** do PAYER.
4. O CNPJ deve ser obtido no cadastro de **Participantes**.
5. O token está localizado na aba **Observação** do participante.
6. Continue a configuração seguindo o **passo a passo do PDF**.

:::tip[Importante]

Confirme se o CNPJ e o token pertencem ao mesmo participante antes de finalizar a configuração.

:::

---

## Testes após a configuração

Após finalizar a configuração:

1. Realize um teste pelo **DT.Shop**.
2. Verifique se a comunicação com o TEF está funcionando corretamente.
3. Confira as **formas de pagamento** configuradas.
4. Verifique se as formas de pagamento utilizadas pelo cliente estão vinculadas corretamente ao TEF.
5. Realize testes nas formas de pagamento.
6. Confirme se as transações são iniciadas e concluídas corretamente.

## Contratar e ativar na Smart POS Multiadquirente

1. No aplicativo, adicione o módulo **Smart POS**.
2. No atendimento aberto no portal, informe o **modelo da Smart POS**.
3. Aguarde o envio do **QR Code de configuração**.
4. Conecte a Smart POS à internet.
5. Acesse o **GertecBox**.
6. Leia o QR Code recebido.
7. Aguarde a instalação automática dos aplicativos:
   - PAYER
   - DT.Shop
8. Realize a configuração dos aplicativos.

:::tip[Importante]

Verifique se a Smart POS possui acesso à internet antes de iniciar a configuração.

:::

Solicite ao gerente ou ao suporte técnico da sua instituição financeira as credenciais de acesso à API PIX:

- Client ID
- Client Secret
- Chave PIX

Além disso, informe que a integração será realizada por meio de um dos seguintes integradores homologados:

- Fiserv
- Software Express
- Payer

Após receber todas essas informações, encaminhe-as para nossa equipe para que possamos realizar a configuração e os testes da integração no ERP Sentus.

Em caso de dúvidas durante o processo, permanecemos à disposição para auxiliar.
