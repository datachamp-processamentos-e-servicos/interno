# Novo Grupo 

Antes de cadastrar um novo usuário, é necessário criar um grupo de usuários (caso ainda não exista).

## Criar um Grupo de Usuários

1. Acesse o módulo **Administrativo**.
2. Clique em **Grupo de Usuários**.
3. Crie um novo grupo.
4. Configure as permissões conforme a necessidade da empresa.
5. Salve as alterações.
