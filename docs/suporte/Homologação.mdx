# Homologação Bancária - Caixa Econômica Federal, Bradesco e Banco do Brasil

## Como realizar a homologação

O processo de homologação destes bancos costuma ser bastante simples e geralmente ocorre por troca de arquivos e validação via e-mail.

Após a solicitação da homologação, o banco encaminhará um e-mail contendo todas as informações necessárias para configuração do portador no Sentus.

## Configuração do Portador

Ao receber o e-mail do banco:

1. Acesse o cadastro do **Portador** no Sentus;
2. Preencha todas as informações conforme informado pelo banco;
3. Revise os dados antes de prosseguir com os testes.

:::tip[Dica]

Mantenha o e-mail recebido arquivado durante todo o processo, pois ele servirá como referência para conferência dos dados do portador.

:::

## Geração dos Arquivos

Após concluir a configuração:

1. Gere aproximadamente **10 boletos de teste**;
2. Gere o arquivo de **Remessa** correspondente aos boletos criados;
3. Verifique se o arquivo foi gerado sem erros.

## Envio para Homologação

Com os arquivos gerados:

1. Anexe os arquivos solicitados pelo banco;
2. Responda ao e-mail recebido ou envie para o endereço informado pelo banco;
3. Aguarde o retorno da equipe responsável pela homologação.

## Conclusão da Homologação

:::warning[Importante]

O banco poderá solicitar ajustes ou novos testes caso identifique alguma inconsistência nos arquivos enviados.

Sempre siga as orientações recebidas por e-mail até a confirmação oficial da homologação.

:::
