# Novo Usuario

## Criar um Grupo de Usuários

Caso ainda não exista um grupo para o usuário, crie um novo grupo.

Acesse:

**Administrativo → Grupo de Usuários**

Após criar o grupo:

1. Edite as permissões conforme a necessidade da empresa.
2. Salve as alterações.

## Cadastrar um Usuário

Com o grupo criado:

Acesse:

**Administrativo → Usuários**

1. Preencha os campos conforme a solicitação da empresa.
2. Vincule o usuário ao grupo criado.
3. Clique em **Salvar**.
