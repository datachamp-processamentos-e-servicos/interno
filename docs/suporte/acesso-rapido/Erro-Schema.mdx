# Erro Schema

Quando o CTe ou MDFe informar "errot modal" ou "falha no Schema".
Normalmente o erro está na aba TRANSPORTE.

Caso não seja a situação faça os passos abaixo.

Baixar o XML;

Copiar o conteúdo do XML;

E consultar no Site Portal do Manifesto Eletrônico de Documentos Fiscais

Dessa forma o site ira mostrar o erro de forma mais detalhada para que assim facilite a correção do mesmo.
