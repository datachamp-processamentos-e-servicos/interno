# Importar Clientes

Este procedimento refere-se à importação de participantes via arquivo CSV.

## Estrutura do arquivo

| Índice | Campo |
|:------:|-------|
| 00 | Código |
| 01 | Documento |
| 02 | IE |
| 03 | IMun |
| 04 | Nome |
| 05 | Nome Fantasia |
| 06 | Logradouro |
| 07 | Número |
| 08 | Complemento |
| 09 | Bairro |
| 10 | CEP (apenas números) |
| 11 | Código IBGE do Município |
| 12 | Nome do Município |
| 13 | Estado |
| 14 | E-mail |
| 15 | Fone 1 |
| 16 | Fone 2 |
| 17 | Observação 1 |
| 18 | Observação 2 |
| 19 | Mensagem 01 |
| 20 | Mensagem 02 |
| 21 | Mensagem 03 |
| 22 | Mensagem 04 |
| 23 | Mensagem 05 |
| 24 | Mensagem 06 |
| 25 | Mensagem 07 |
| 26 | Portador (ID) |
| 27 | Forma de Pagamento (ID) |
| 28 | Grupo do Participante (ID) |
| 29 | Representante (ID ou CPF/CNPJ) |
| 30 | Agrupador / Lote / Carga |
| 31 | Data Fundação / Nascimento ( dia / mês / ano) |
