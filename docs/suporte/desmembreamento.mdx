# Desmembrar pedido

1. Selecione o **Pedido**.
2. Clique em **Opções**.
3. Informe os itens que deverão ser desmembrados.

---

## Exemplos de utilização

### Canal Embutidos

Os pedidos realizados pelos vendedores/representantes contêm itens de duas empresas (**JJW** e **WRJ**).

Após o desmembramento, o **emitente** é alterado conforme os itens de cada empresa.

### RB Distribuição

Os pedidos realizados pelos vendedores/representantes são desmembrados por fornecedor.

Após o desmembramento, o **Zezi** gera as ordens de compra conforme o fornecedor correspondente.
