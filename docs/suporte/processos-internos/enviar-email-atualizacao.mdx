# Passo a passo para envio de e-mail e atualização changelog de nova versão

Este procedimento descreve o envio do e-mail de atualização aos clientes e a publicação do PDF de alterações no Sentus.

---

## Envio do e-mail

### Exportar os destinatários

1. Acesse **Tenant Master → Administrativo → Tenants**.
2. Clique em **Opções → Exportar E-mail**.
3. Abra o arquivo utilizando o **WordPad**.
4. Copie todos os endereços de e-mail.

### Configurar os destinatários

| Equipamento | Campo |
|-------------|-------|
| PC do Guilherme | **CCo** |
| Demais computadores | **Bcc** |

:::warning[Destinatário obrigatório]

O campo **Para** deve conter obrigatoriamente:

`datachamp@datachamp.com.br`

Caso contrário, o e-mail poderá ser enviado com um destinatário inválido.

:::

### Corpo do e-mail

Copie o conteúdo disponível em:

```text
G:\_Sentus\Email de atualizações do Sentus
```

Cole o texto no corpo da mensagem.

---

## Atualização do PDF

### Conectar ao servidor

Abra o **WinSCPPortable** disponível no computador do Guilherme.

Conecte-se utilizando:

```text
root@datachamp_ajuda
```

### Localizar a pasta

Navegue até:

```text
/var/www/datachamp.com.br/html/ajuda
```

### Publicar o arquivo

Copie o novo PDF para esta pasta.

:::danger[Nome do arquivo]

O PDF deve possuir exatamente o seguinte nome:

```text
changelog.pdf
```

Qualquer outro nome impedirá a atualização do documento no sistema.

:::

### Validação

Após concluir o upload:

1. Abra o Sentus.
2. Acesse a ajuda.
3. Confirme que o PDF exibido corresponde à nova versão.

:::tip[Boa prática]

Sempre valide o documento publicado antes de finalizar o procedimento.

:::
