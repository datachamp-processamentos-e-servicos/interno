# Gerar bloco H

Acesse:

```text
Tributos → Repositório de Arquivos → Novo
```

Configure a geração do arquivo conforme a necessidade.

Exemplo de configuração para **EFD Fiscal (Bloco H)**:

- **Data Inicial:** Período desejado.
- **Data Final:** Período desejado.
- **Tipo do Arquivo:** EFD Fiscal (Bloco H).
- **Finalidade:** Original.
- **Situação Fiscal:** Conforme necessidade.
- **Recibo:** Deixar em branco, quando não aplicável.
- **Inventário:** Não se Aplica.
- **Data Inventário:** Informar quando habilitado.
- **Bloco K:** Selecionar a opção correspondente.
- **Produto Acabado:** Conforme necessidade.

Após preencher as informações, gere o arquivo e faça o download.
