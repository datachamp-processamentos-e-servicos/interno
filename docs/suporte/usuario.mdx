# Novo Grupo/Usuário

## Criação do Grupo

Antes de cadastrar o usuário:

1. Acesse:

  ```
  Administrativo → Grupo de Usuários
  ```

2. Crie o grupo.

3. Configure as permissões necessárias.

---

## Cadastro do Usuário

Com o grupo criado:

1. Acesse:

   ```
   Administrativo → Usuários
   ```
