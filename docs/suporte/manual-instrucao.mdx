# Manual de Instruções

## Visualizar NF-e com mais de 7 dias

Por padrão, o sistema exibe apenas as NF-e emitidas nos últimos **7 dias**.

Para consultar notas emitidas anteriormente, siga os passos abaixo:

1. Acesse o módulo **Comercial**.
2. Clique em **NF-e / NFC-e**.
3. Clique na **Lupa** (localizada no canto superior direito).
4. Informe o período desejado nos campos **De** e **Até**.
5. Realize a pesquisa.

## Exportar XML e PDF das NF-e/NFC-e

Para exportar os arquivos XML e PDF das notas fiscais:

1. Acesse o módulo **Comercial**.
2. Clique em **NF-e**.
3. Selecione as notas desejadas.
4. Clique em **Opções**.
5. Selecione **Exportador**.
6. Escolha a opção **XML - LISTADAS** e clique em **Exportar**.
7. Em seguida, escolha **PDF - LISTADAS** e clique em **Exportar**.

## Enviar os arquivos ao contador

Após a exportação:

1. Acesse a pasta onde os arquivos foram salvos.

O local padrão é:

- **Meu Computador**
- **Downloads**

2. Localize os arquivos exportados.
3. Anexe os arquivos XML e/ou PDF ao e-mail.
4. Envie-os ao contador.
