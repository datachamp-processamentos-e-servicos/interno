# Anydesk Bloqueado

Para utilizar o AnyDesk durante o atendimento, siga as orientações abaixo:

1. Utilize apenas o **executável do AnyDesk**, sem realizar a instalação do programa.

2. Caso o AnyDesk já esteja instalado no computador, desinstale-o e deixe apenas o executável na Área de Trabalho.

3. Limpe o cache do AnyDesk:
   - Abra o menu **Iniciar** e pesquise por **%appdata%**.
   - Acesse a pasta **Roaming**.
   - Abra a pasta **AnyDesk**.
   - Exclua todo o conteúdo existente dentro dessa pasta.

4. Execute o AnyDesk normalmente para realizar o atendimento.

5. Ao finalizar o atendimento, o AnyDesk poderá solicitar a instalação do programa. **Não instale** e informe ao cliente que essa instalação não é necessária.
