# Homologação de Cobrança Bancária

## Sicredi

### Cadastrar o portador

Utilize como base um cliente que já possua o portador configurado, por exemplo:

- Transmaria
- Gobbo
- Boscaini

Preencha os seguintes dados:

- **Documento do Correntista:** CNPJ
- **Convênio:** Número da conta **sem o dígito**

:::info

Confirme o **Complemento** com a agência. Normalmente o valor é **08** ou **31**.

:::

### Gerar a remessa

1. Lance uma cobrança para a **Datachamp** em **Títulos a Receber**, no valor de **R$ 10,00**.
2. Gere a remessa em:

```text
Cobranças Bancárias → Remessas
```

3. Faça o download da **Remessa** e do **Boleto em PDF**.
4. Envie ambos para o e-mail do banco.

## Demais bancos

### Cadastrar o portador

Utilize como base um cliente que já possua o mesmo portador configurado.

Preencha:

- **Documento do Correntista:** CNPJ
- **Convênio:** Número da conta **sem o dígito**

### Gerar a remessa

1. Lance uma cobrança para a **Datachamp** em **Títulos a Receber**, no valor de **R$ 10,00**.
2. Gere a remessa em:

```text
Cobranças Bancárias → Remessas
```

3. Faça o download da **Remessa** e do **Boleto em PDF**.
4. Envie os arquivos para o e-mail do banco.
5. Solicite que o cliente envie a remessa ao banco para homologação.
