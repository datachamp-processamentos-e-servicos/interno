# Como enviar o e-mail

---

## Exportar os destinatários

1. Acesse **Tenant Master → Administrativo → Tenants**.
2. Clique em **Opções → Exportar E-mail**.
3. Abra o arquivo utilizando o **WordPad**.
4. Copie todos os e-mails.

## Envio

- **PC do Guilherme:** utilize o campo **CCo**.
- **Demais computadores:** utilize o campo **Bcc**.

:::warning

O campo **Para (To)** deve conter obrigatoriamente:

`datachamp@datachamp.com.br`

Caso contrário, o e-mail poderá ser enviado com um código incorreto.

:::

## Corpo do e-mail

Copie o conteúdo localizado em:

`G:\_Sentus\Email de atualizações do Sentus`

e cole no corpo do e-mail.

---

# Atualizar o PDF

## Conectar ao servidor

Abra o **WinSCPPortable**.

Conecte-se em:

`root@datachamp_ajuda`

Acesse o diretório:

`/var/www/datachamp.com.br/html/ajuda`

## Upload

Envie o novo PDF utilizando obrigatoriamente o nome:

`changelog.pdf`

:::info

Após o upload, abra o Sentus e confirme que o novo documento está sendo exibido corretamente.

:::
