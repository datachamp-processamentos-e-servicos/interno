# Remessa de onserto 

## Operação Tributária

Utilize:

- **S.915** para **saída**.
- **E.915** para **entrada**.

**Descrição da operação:**

```text
REMESSA DE MERCADORIA OU BEM PARA CONSERTO OU REPARO
```
