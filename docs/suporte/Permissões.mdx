# Configurar permissões da tenant

No **Sentus Master**, acesse:

```text
Administrativo → Tenants
```

1. Localize a tenant desejada.
2. Clique na **engrenagem** localizada no canto direito.
3. Configure as permissões necessárias.

:::info

As permissões devem ser configuradas de forma **idêntica em ambas as tenants**.

:::
