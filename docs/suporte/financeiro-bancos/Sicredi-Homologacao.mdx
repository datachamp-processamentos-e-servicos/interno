# Homologação Bancária - Sicredi

## Como realizar a homologação

O processo de homologação junto ao Sicredi é simples e realizado por meio do Portal de Homologação.

Para iniciar o processo, siga os passos abaixo:

1. Entre em contato com a agência do cliente;
2. Solicite ao gerente o cadastro para **Homologação via Portal**;
3. Aguarde o retorno do banco com as informações necessárias para o cadastro.

Normalmente, o Sicredi solicitará os seguintes dados:

- Nome;
- Telefone;
- E-mail.

:::tip[Dica]

Os dados do correntista podem ser localizados dentro do próprio Portal de Homologação e utilizados para o preenchimento do campo **Portador** no Sentus.

:::

## Acesso ao Portal

Após a confirmação do cadastro, acesse o Portal de Homologação do Sicredi:

[https://portal-homologacao.app.sicredi.com.br](https://portal-homologacao.app.sicredi.com.br)

Realize o login utilizando as credenciais fornecidas pelo banco.

## Envio dos arquivos para homologação

Após acessar o portal, siga os passos abaixo:

1. Clique em **Cobrança**;
2. Clique em **Upload de Arquivos**;
3. Selecione a **Cooperativa**;
4. Selecione o **Beneficiário**;
5. Clique em **Buscar**.

Após a consulta, serão exibidas as informações da conta homologada, incluindo:

- Cooperativa;
- Beneficiário;
- Posto;
- Conta Corrente;
- Layout;
- Sequencial.

## Configuração no Sentus

Com os dados exibidos no portal:

1. Acesse o cadastro do **Portador** no Sentus;
2. Preencha corretamente todas as informações retornadas pelo portal;
3. Gere dois ou três boletos de teste;
4. Gere o arquivo de remessa;
5. Realize o upload do arquivo no Portal de Homologação.

## Validação da homologação

Após o envio do arquivo, o próprio portal realizará a validação.

:::warning[Importante]

O resultado da homologação é exibido imediatamente após o processamento do arquivo.

Caso existam inconsistências, o portal apresentará os erros encontrados para correção. Se não houver erros, a homologação será considerada concluída com sucesso.

:::
