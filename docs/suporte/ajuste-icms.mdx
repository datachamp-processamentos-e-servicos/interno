# Ajuste ICMS 

Este procedimento deve ser realizado **somente quando solicitado pelo cliente ou pelo contador**.

## Como realizar

1. Acesse as **Matrizes Tributárias**.
2. Localize as matrizes que possuem o caractere **`$`**.
3. Realize o ajuste do crédito do ICMS conforme a solicitação.
4. Salve as alterações.

:::warning[Importante]

Efetue essa alteração apenas mediante solicitação do cliente ou do contador responsável.

:::
