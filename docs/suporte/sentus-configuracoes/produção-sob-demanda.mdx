# Produção Sob Demanda

Acesse:

```text
Estoque → Conferência
```

Siga os passos abaixo:

1. Pesquise pelos itens com **Saldo Menor que Zero**.
2. Clique em **Opções → Produção Sob Demanda**.
3. Clique em **Opções → Zerar Saldo**.
4. Pesquise novamente pelos itens com **Saldo Menor que Zero**.
5. Clique em **Opções → Transferir Saldo**.
