# Código de Barras

A cliente recebeu uma encomenda contendo **4 tipos de nozes**, porém a nota fiscal possuía apenas **um único item**.

Como todos os produtos possuíam **o mesmo valor**, foi adotado o seguinte procedimento:

- Foi realizada a entrada utilizando apenas **um único item**.
- Todos os **códigos de barras** foram vinculados a esse mesmo cadastro.
- Os demais itens foram **inativados**.

:::info

Esse procedimento foi possível porque todos os produtos possuíam o mesmo preço e a nota fiscal continha apenas um item.

:::
